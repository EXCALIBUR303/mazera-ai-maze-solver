# MAZERA AI Maze Solver

MAZERA is a React and Vite maze pathfinding visualizer. It compares classical graph-search algorithms on generated mazes and shows explored nodes, final path, and run metrics.

## Features

- Maze patterns: Random, Spiral, Zigzag, and Open Field
- Algorithms: BFS, DFS, Dijkstra, A*, Greedy Best-First, and Bidirectional Search
- Animated exploration and shortest-path visualization
- Live metrics for explored nodes, path length, time, and efficiency score
- Recent maze history stored locally in the browser

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
